# React Exercise

Repository latihan React yang disusun secara bertahap dari manipulasi DOM dasar hingga pengembangan aplikasi berbasis komponen.

## Materi

| Direktori | Materi |
| --- | --- |
| `1-pendahuluan` | DOM, JSX, komponen, props, list, event, dan state |
| `2-instalasi-dan-konfigurasi` | Instalasi React dan konfigurasi Vite |
| `3-tic-tac-toe` | State, props, immutable updates, dan riwayat permainan |
| `4-catatan-belanja` | Form, pengelolaan daftar, sorting, dan lifting state up |
| `5-semua-tentang-component` | Pemecahan dan komposisi komponen |

## Prasyarat

- Node.js
- npm atau pnpm

## Menjalankan Latihan Pendahuluan

Buka file `index.html` pada salah satu subdirektori di dalam `1-pendahuluan` menggunakan browser.

## Menjalankan Aplikasi Vite

Masuk ke direktori aplikasi yang ingin dijalankan, lalu instal dependensi dan mulai development server.

Contoh:

```bash
cd 3-tic-tac-toe
npm install
npm run dev
```

Direktori aplikasi Vite:

- `2-instalasi-dan-konfigurasi`
- `3-tic-tac-toe`
- `4-catatan-belanja/final-app`
- `5-semua-tentang-component/starter-app`

## Perintah

Jalankan perintah berikut dari direktori aplikasi Vite.

| Perintah | Fungsi |
| --- | --- |
| `npm run dev` | Menjalankan development server |
| `npm run build` | Membuat production build |
| `npm run preview` | Menjalankan preview production build |
| `npm run lint` | Menjalankan pemeriksaan lint |
